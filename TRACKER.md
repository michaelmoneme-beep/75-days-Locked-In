# 75 Days to Job-Ready: TRACKER

Start: Sat Oct 31, 2026 (Day 1) | Finish: Wed Jan 13, 2027 (Day 75) | Budget: 2 hrs/day
Stack: TypeScript + React + Node + PostgreSQL

## Rules
1. A day counts only if the deliverable AND the checkpoint are both ticked.
2. Minimum viable day: 20 minutes + 1 commit keeps the streak alive.
3. Never miss twice. Missed deliverable goes first the next day.
4. Failed assessment = one remediation day before advancing.
5. AI explains, reviews and quizzes. It does not write the deliverable. You must be able to explain every line you submit.
6. One commit minimum per day, ticking this file in the same commit.

## Phases
1. Foundations (Days 1-15)
2. Web fundamentals, SQL, APIs (Days 16-35)
3. Flagship project (Days 36-58)
4. Second project, Docker, CI/CD, AI integration (Days 59-68)
5. Portfolio, interviews, applications (Days 69-75)
